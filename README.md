Transport Company
Project Description

The Indian Transport Company Management System is a simple Python-based project developed to manage basic activities of a transport company. The project is designed using basic Python concepts such as functions, lists, dictionaries, loops, conditional statements, user input, and modules.

The project is divided into four separate modules: "booking.py", "vehicle.py", "driver.py", and "fare.py". A fifth file, "main.py", imports all these modules and provides a menu through which the user can operate the system.

The booking module is used to add and display transport bookings. The vehicle module stores basic vehicle information, while the driver module stores driver details. The fare module calculates the transport cost based on the distance travelled and the rate per kilometre.

The main purpose of this project is to demonstrate how a real-world problem can be divided into smaller parts using Python modules. It also helps in understanding how different functions and modules can work together in one program.

This project is developed at a basic first-semester Python programming level, making it easy to understand, run, and explain during a project presentation or viva.
